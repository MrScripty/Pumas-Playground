# Source and evidence provenance

Pumas Playground was extracted with fresh Git history from
[MrScripty/Pumas-Library](https://github.com/MrScripty/Pumas-Library), directory
`tools/model-playground`, at commit
[`bd982b67bb34e57088b5db466b3761809b6a03f6`](https://github.com/MrScripty/Pumas-Library/tree/bd982b67bb34e57088b5db466b3761809b6a03f6/tools/model-playground)
on the unmerged `feat/model-testing-playground` branch.

The upstream MIT license and `Copyright (c) 2025 MrScripty` notice are preserved
verbatim in [LICENSE](LICENSE). The extraction changes launch paths, public source
links and optional test configuration, and adds standalone contributor guidance
and CI. Runtime code, model weights, third-party libraries and dependency caches
are not copied into this repository.

The six finite adapters consume public Pumas v1 contracts inspected at
[`ad31e391dcd94c204b3fcd748cc98d27b3281e65`](https://github.com/MrScripty/Pumas-Library/tree/ad31e391dcd94c204b3fcd748cc98d27b3281e65).
Pumas Library remains independently licensed and maintained by its owner, and is
an external HTTP runtime dependency. Node.js is the execution environment;
Playwright and Chromium are optional, separately installed test tools.

The files under `evidence/` include public observations produced by this work.
Original JSON receipts and screenshots are retained with their original dates,
source SHAs and qualification limits. Their checkout SHAs refer to the Pumas
feature branch. They are not observations of the standalone repository's CI.
The tiny untrained ONNX graph was generated by Pumas' existing public fixture
tooling and executed using its pinned ONNX Runtime; neither the graph, native
runtime nor Pantograph's BERT weights are redistributed here. The optional real
smoke reads that tooling from an explicitly selected external Pumas checkout.

Simulated adapter responses and PNG/PCM fixtures under `test/` are test-only
inputs. They are never substituted for inference in the normal launcher.
See [verification](evidence/verification.md) for measured coverage and the known
mixed-length ONNX batch failure.
